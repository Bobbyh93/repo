# Slide Grammar

Use this loop for every major concept block:

```text
Patient cue -> Student prediction -> Core concept -> Exam anchor -> Common trap -> Practice item -> Rationale -> Takeaway
```

## Compact block variants

### 4-slide concept loop

1. Cue + prediction
2. Core concept + visual
3. Checkpoint item
4. Rationale + takeaway

### 6-slide concept loop

1. Patient cue
2. Student prediction
3. Core concept
4. Exam anchor + common trap
5. Practice item
6. Rationale + transfer prompt

### Capstone loop

1. Scenario update
2. Cue recognition
3. Prioritization
4. Next action
5. Rationale
6. Exit check
