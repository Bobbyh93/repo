# Learner-Facing Contract

Visible slides must teach the learner directly.

## Prohibited visible-slide language

- teaching move
- presenter intent
- script focus
- facilitator note
- production note
- visual production note
- instructor should
- use this slide to

## Required visible-slide features

- student-facing prompt or explanation
- exam anchor when concept-heavy
- common trap when misconception risk is high
- clear answer reveal or rationale slide after retrieval

## Speaker notes may contain

- instructor guidance
- expected answers
- timing
- rationale expansion
- remediation cues
- optional debrief language
