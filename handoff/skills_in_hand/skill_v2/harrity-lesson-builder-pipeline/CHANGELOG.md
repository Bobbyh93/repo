# Changelog

## v0.3.0 - 2026-05-09

### Changed

- Reframed default output from lesson-package production to learner-facing exam-prep content experience.
- Added explicit audience/output-mode guardrail.
- Added required slide grammar: patient cue -> prediction -> concept -> exam anchor -> trap -> item -> rationale -> takeaway.
- Added learner-visible vs speaker-notes separation rule.
- Added student-reception QA.
- Added exam-anchor density and rationale coverage requirements.
- Added artifact truthfulness requirement.

### Added

- Learner-facing contract reference.
- QA gates reference.
- Student reception review reference and schema.
- Slide/item/QA/assessment blueprint templates.
- Package validation script.

### Removed from default behavior

- Defaulting to instructor guide or production package as the center artifact.
- Visible slide language such as presenter intent, teaching move, or production note.
