# CJM Concept Model Crosswalk

## Purpose

Map every lesson package directly to the NCSBN Clinical Judgment Measurement Model (CJMM) while preserving the chapter concept model.

## CJMM Functions

Use these six function labels consistently:

1. **Recognize cues** - identify relevant and important information from the patient, record, environment, history, assessment, or data.
2. **Analyze cues** - connect cues to the patient's clinical presentation and underlying concept.
3. **Prioritize hypotheses** - rank possible concerns by urgency, likelihood, risk, time pressure, difficulty, and consequences.
4. **Generate solutions** - identify expected outcomes and possible nursing interventions.
5. **Take action** - implement the solution that addresses the highest priority.
6. **Evaluate outcomes** - compare observed outcomes with expected outcomes and decide what changes.

## Lesson Concept Spine

Use this spine for each major concept:

`concept -> normal function -> cue -> meaning -> risk -> nursing response -> evaluation`

Example for early pregnancy:

`placenta -> exchange support -> bleeding/pain/decreased fetal support cues -> possible compromised support -> maternal/fetal risk -> assess and escalate when urgent -> monitor response and follow-up`

## Crosswalk Requirements

Every package must include a slide-by-slide map with these fields:

- slide number
- slide title
- concept lane
- concept objective
- CJMM function(s)
- learner task
- expected evidence of learning
- remediation target if missed

## Minimum Coverage Standard

A complete package should include at least:

- 2 slides or activities for recognizing cues.
- 3 slides or activities for analyzing cues.
- 2 slides or activities for prioritizing hypotheses.
- 1 slide or activity for generating solutions.
- 1 slide or activity for taking action.
- 1 slide or activity for evaluating outcomes.

If the deck is short, combine functions intentionally and document the combination in the assessment map.

## Mapping Pattern

| Lesson component | Primary CJMM function | Evidence learner should produce |
|---|---|---|
| high-level map | recognize cues | names relevant domains or cues |
| structure-function slide | analyze cues | explains why a cue happens |
| sequence/timeline task | analyze cues | places events in safe order |
| risk sort | prioritize hypotheses | separates urgent from expected findings |
| teaching script | generate solutions / take action | gives clear patient-centered response |
| capstone next-action item | prioritize hypotheses / take action | chooses safest immediate action |
| debrief | evaluate outcomes | explains what outcome or follow-up confirms safety |

## Item Stem Verbs by CJMM Function

- **Recognize cues:** identify, select, match, notice, list, mark.
- **Analyze cues:** explain, connect, compare, infer, sequence, categorize.
- **Prioritize hypotheses:** rank, sort, choose first, determine most concerning.
- **Generate solutions:** propose, plan, select teaching, identify expected outcome.
- **Take action:** implement, respond, document, notify, teach, reassess.
- **Evaluate outcomes:** reassess, compare, determine effectiveness, modify plan.

## Concept Model Rule

Do not treat CJMM as a separate add-on at the end of the lesson. Embed CJMM in the concept model:

- Concept lanes organize what the learner is studying.
- CJMM functions organize what the learner must do with the concept clinically.
- Assessment items test both: content accuracy and judgment operation.
