# Quiz and Question Remediation Rules

## Goal

Use quiz performance and learner questions to drill down from the high-level concept map to the exact missed thinking operation.

## Accepted Input Forms

The user may provide:

- item-level quiz export
- score by objective
- list of missed questions
- learner questions from class
- informal notes such as "they keep missing implantation and teratogens"

## Miss Classification

Classify each miss into one primary type and, if useful, one secondary type.

| Miss type | Diagnostic sign | Best remediation slide/activity |
|---|---|---|
| vocabulary/fact | learner cannot define term or identify part | micro-card + retrieval prompt |
| structure-function | learner knows term but cannot explain why it matters | match structure to cue + debrief |
| sequence/timing | learner places steps in wrong order | timeline reorder + checkpoint |
| cue recognition | learner misses what data matters | cue spotting case |
| cue analysis | learner notices cue but misinterprets meaning | cue -> meaning reasoning cards |
| risk priority | learner cannot decide urgent vs expected | urgency sort |
| solution generation | learner knows risk but cannot choose teaching/intervention | patient teaching script |
| action selection | learner chooses unsafe or delayed action | best next action case |
| outcome evaluation | learner cannot tell whether action worked | expected vs observed outcome compare |
| communication | learner uses unclear or overcertain patient language | script rewrite |

## Thresholds

Use these defaults unless the user provides their own standard:

- **80% or higher:** keep on map, reinforce with retrieval only.
- **65% to 79%:** add one short drill or checkpoint.
- **50% to 64%:** add a teaching slide plus an active task.
- **below 50%:** add a map revisit, foundation rebuild, active task, and capstone tie-in.

## Decision Tree

1. Does the miss happen before the learner can identify relevant information?
   - Yes: target recognize cues.
2. Does the learner identify the cue but fail to explain physiology, mechanism, or meaning?
   - Yes: target analyze cues.
3. Does the learner understand the cue but choose the wrong priority?
   - Yes: target prioritize hypotheses.
4. Does the learner know the priority but not the teaching, intervention, or next step?
   - Yes: target generate solutions or take action.
5. Does the learner act but fail to reassess or evaluate effectiveness?
   - Yes: target evaluate outcomes.

## Remediation Output Format

For each major weak area, produce:

- map location: which concept lane and objective
- missed thinking operation: CJMM function
- likely misconception
- 1-slide fix
- 1 active-learning task
- 1 retrieval item
- how the educator will know it improved

## Example

Learners miss questions about bleeding after positive pregnancy test.

- Map location: signal lane.
- Missed thinking operation: risk priority.
- Likely misconception: all early bleeding is normal spotting.
- 1-slide fix: expected vs urgent bleeding cues.
- Active task: sort cues into escalate now vs assess/follow up.
- Retrieval item: "Which cue requires immediate escalation and why?"
- Improvement evidence: learner names amount, pain, dizziness/syncope, fever, tissue passage, and gestational context as risk modifiers.
